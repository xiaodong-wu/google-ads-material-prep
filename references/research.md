# 研究口径与证据

优先用户真实数据、政府/海关、监管机构、行业协会和原始公开研究。付费报告摘要只支持公开部分。首页可访问不等于数据免费可得；登录、订阅或查询失败记录为限制。

每条数值记录产品定义、地区、指标、年份/期间、数值、币种/单位、发布者、发布日期、URL、访问日期、证据状态。动态查询另保存条件和导出文件/截图，以便复现；写入 `_核验/来源与事实.md`。

## 仅有的五个核心维度

以海关数据分析师与海外数字营销专家的视角研究目标网站所属行业。08正文只包含以下五章，按此顺序组织；缺少数据时在对应章注明待验证，不增设额外章节。

1. **行业全球市场规模与CAGR预测**：近3–5年趋势及未来展望。区分收入规模、产值、贸易额、台数；不用相邻行业总量代表细分市场。预测注明基年、终年、发布时点和范围；不同机构口径不混拼。自行计算使用`(终值/初值)^(1/年数)-1`，标为计算值；无可比数据不计算。
2. **谷歌搜索趋势与热门搜索国家/地区分布**：记录关键词/主题、地区、时间窗、类别、搜索类型和导出日期。Trends的0–100是归一化兴趣指数，不是搜索量/份额/采购人数；不直接比较不同查询批次的绝对指数。国家兴趣图不能单独证明进口需求。未得到实际结果就在本章标待验证，不画假曲线。
3. **目标行业主要进口需求国与重点采购市场**：按洲/区域划分。建立产品→候选HS映射，注明版本、覆盖范围和归类不确定性。按相同年份、币种、贸易流、伙伴口径比较；区分reporter/partner、进口/出口、总额/净额、金额/数量。注明统计滞后、转口枢纽和镜像数据。进口额不等于终端销售规模；本章不加入广告Tier分层或预算建议。
4. **行业进出口政策、认证门槛及合规要求**：按产品×原产国×目的国×用途查询现行主管机构、进出口限制、关税、认证及准入要求，注明生效日期。优惠税率核对原产地资格。CE/FCC/UL/RoHS等是可能适用的示例，不机械套用于全部行业，也不把自愿认证一律写成强制要求。资料不足写“可能适用，待按产品核验”；不扩展到Ads账户资格、获客表单或网站隐私整改。
5. **竞争格局、市场集中度及竞争壁垒分析**：区分品牌商、制造商、经销商与平台，引用真实产品、渠道、认证、服务证据。无同口径份额数据就注明集中度待验证，不编造CR值；可给有依据的定性判断。不凭网站视觉或知名度推断排名，不加入客户网站整改清单或广告竞价计划。

## HTML版式与范围

单文件使用UTF-8、viewport、内联CSS、手机断点和打印样式。用统一字体层级、间距、配色、图表和可横向滚动的表格呈现；正文离线可读，不依赖远程字体或脚本。图表标明期间、单位、底层数据与来源；缺数据写待验证，不写成0。

结构固定为`header + 可选五章导航 + main内五个section + footer`。每个section有且只有一个h2，章内可用h3、卡片、图表或表格；不要另建section。五个section依次使用以下id，供导出校验识别：

| id | 对应核心章节 |
|---|---|
| market-size | 行业全球市场规模与CAGR预测 |
| search-trends | 谷歌搜索趋势与热门国家/地区 |
| import-markets | 按洲/区域的进口需求与重点采购市场 |
| policy-compliance | 行业进出口政策、认证与合规 |
| competition | 竞争格局、集中度与壁垒 |

页眉只作标题、行业/目标网站和日期标识，不附摘要、执行结论或总体推荐。正文不得有第六章，也不得在五章内夹带投放国家Tier、出价、执行计划、交付清单、网站审计等额外内容。证据链接、来源时点、计算口径和局限紧跟相关数据或放在本章的小字说明中，不另设方法/来源/限制章节。详细核验底稿留在`_核验/`。

页脚`footer`列出四个可点击的公开参考入口：

- `https://thinkwithgoogle.com/`（Think with Google市场趋势洞察）
- `https://wits.worldbank.org/`（WITS关税与贸易数据库）
- `https://www.macmap.org/`（ITC Market Access Map关税与合规壁垒查询）
- `https://trends.google.com/trends/`（Google Trends）

页脚只放参考入口和必要署名/日期，不增加分析模块。具体数值仍须在正文附近链接实际查询或研究页面，不能用入口证明结果。
